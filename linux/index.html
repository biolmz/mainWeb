⚙️ 控制

点击终端后即可输入，使用 Ctrl+Shift+空格 切换键盘布局（中文/英文）。

🧪 操作系统实验 (C 语言)

一键在系统内生成源码 → gcc 编译 → 运行。也可以手动 cd /opt/labs 查看预置源码。

📜 内核日志

启动串口输出即内核启动日志（dmesg）。运行中可输入 dmesg | tail 查看。

🔗 9P 宿主文件系统

9P 模式：把网站目录中的文件通过 virtio-9p 挂载到客户机。

挂载后，浏览器端目录 images/9p/base 的内容会出现在 /mnt/9p。可读写实验。

💡 使用说明

  • 内核：Linux 5.15 (TinyCore 13.1 x86)
  • 工具链：gcc 11.2 / g++ / make / binutils（已预装进 initramfs）
  • 登录：root（自动登录）
  • 实验代码位于 /opt/labs/*.c
