代码是工具，生命是研究对象，哲学是底层操作系统。

游走在湿实验与干实验之间，用计算思维解构生物问题，用哲学思维审视一切前提。

我是 Kael，一名生物工程专业的学生与研究者。对生命的运行机制着迷——从 DNA 双螺旋到蛋白质折叠，从代谢通路到生态系统。

同时也是一个重度 计算机 爱好者。相信计算不只是工具，更是一种思维方式。生物信息学是我将两者融合的桥梁：用算法解读基因组，用数据驱动发现。

在技术与科学之外，哲学是我审视一切的底层框架。生命的意义是什么？意识从何而来？当我们用代码模拟生命时，我们究竟在创造什么？这些问题驱动我不断思考与探索。

四个维度的交叉探索

不是四个独立的领域，而是一个有机整体——生物学提供数据与问题，计算机学提供工具与方法，生物信息学是桥梁，哲学是底层驱动。

Bioengineering

研究生命系统的工程化改造——基因编辑、代谢工程、合成生物学。在湿实验室里理解生命的运作逻辑，用工程思维重新设计生物系统。

基因工程 合成生物学 发酵工程 蛋白质工程

计算机科学

Computer Science

编程不仅是一种技能，更是一种思维方式。从算法设计到系统架构，从前端可视化到后端数据处理，用代码构建工具、解决问题、表达想法。

Python 算法 Web开发 Linux Docker

生物信息学

Bioinformatics

站在生物学与计算机科学的交叉点上。用算法分析基因组数据，用统计学发现生物学规律，用可视化呈现生命的复杂性。让数据说话。

哲学

Philosophy

追问「为什么」而不是「怎么做」。生命的本质是什么？意识从何而来？技术伦理的边界在哪？哲学不是空谈，而是对一切前提的审视与重构。

科学哲学 生命伦理 认知科学 技术哲学

还原论与整体论

生命可以拆解为分子，但意识不能还原为神经元。真正的理解，需要在分解与整合之间反复切换。

技术与伦理

基因编辑让我们成为造物主，但我们有资格吗？技术的边界不在能力，而在智慧。能做不等于应该做。

🧩

涌现与复杂性

简单的规则可以涌现出复杂的生命。蚁群无中心，却能构建精密巢穴。代码无灵魂，却能模拟世界。涌现，是宇宙最深的魔法。
