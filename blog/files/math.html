00先说清楚：为什么 AI 非要数学不可

很多人以为 AI 是"写规则"。恰恰相反 —— AI 是用数学代替规则。

传统程序 vs 机器学习：两种完全不同的思路

假设你要写一个程序识别"这张图是不是猫"。传统编程的思路是：写一堆 if-else，找出猫的特征 —— 有耳朵、有胡须、是毛茸茸的。但你很快会崩溃：折耳猫呢？趴着的猫呢？水墨画里的猫呢？规则永远写不完。

机器学习的思路完全不同：我不告诉你规则，我给你一万张标注好的图，你自己找规律。而"找规律"这件事，在数学上有唯一严谨的含义 —— 在一个巨大的函数空间里，找到那个让误差最小的函数。

📜传统编程

人写规则 → 机器执行。
输入 数据 + 规则，输出 答案。
规则复杂到一定程度就写不动了。

📈机器学习

机器找规则 → 人定目标。
输入 数据 + 答案，输出 规则。
规则就是那堆数学参数。

一个动作，四个数学问题

拿"让 AI 认出图片里的数字 8"举例。整个流程可以拆成四步，每步对应一门数学：

把图片变成数字

一张 28×28 的灰度图，就是 784 个 0~255 的数。它们不是一堆散数，而是一个 784 维的向量。→ 线性代数要回答：怎么度量两个向量的接近程度？

让数字一层层传递

每一层的输出 = 上一层输出 × 权重矩阵 + 偏置。信息在矩阵乘法中被反复"搅拌"。→ 线性代数要回答：矩阵乘法到底做了什么？

知道错了多少，然后往回改

算出预测和真实答案的差距（损失），再求这个损失对每一个参数的导数，按导数反方向微调。→ 微积分要回答：怎么高效地求几百万个参数的导数？

在千万个参数里找到最优解

参数空间维度极高，不可能暴力搜索。只能一步步试探着往下走。→ 最优化 + 概率统计要回答：往哪走、走多远、怎么不被局部坑住？

◆ 记住这条主线

线性代数负责"表达能力"（网络能表示什么函数）；微积分负责"学习能力"（怎么从错误里改进）；概率统计负责"判断能力"（输出有多可信）；最优化负责"落地能力"（如何真的收敛到好解）。四者缺一不可。

你不需要成为数学家

一个常见焦虑："我数学不好，是不是学不了 AI？"好消息是：AI 工程中用到的数学，99% 集中在四五个核心概念上，而且它们都有极强的几何直觉。你需要的是"看懂"而不是"手推"。真正的计算交给 PyTorch，它比你手算快一亿倍。

✓ 本教程的使用方式

每节的交互演示都可以直接拖动，不要只看不动。看到公式先别急着理解符号 —— 先去看上面的图在动什么，图看懂了，公式自然就通了。

01向量：AI 眼中的世界就是一串数字

在 AI 里，没有"文字"、没有"图片"、没有"声音"，只有向量。向量是 AI 唯一的母语。

向量是什么？两个角度

向量有两种理解方式，你必须在它们之间自由切换：

📍几何视角：带箭头的位移

一个向量就是"从原点出发，往某个方向走多远"。二维向量 (3, 2) 就是"向右 3，向上 2"。它有方向和长度两个属性。

📋数据视角：一组特征

一个人的向量 [身高, 体重, 年龄] = [175, 68, 24]。一个词的向量可能是 768 个数字，表示它在"语义空间"里的位置。

这两个视角其实是同一件事：把 n 个特征看成 n 维空间里的一个点。下面的演示里，拖动两个滑块改变向量的分量，箭头会跟着动 —— 这就是"数据即箭头"。

向量的加法：首尾相接
蓝色是向量 a，紫色是向量 b，橙色 a+b 是你把 b 平移到 a 的箭头末端后，从原点连过去的结果。这就是平行四边形法则。

向量的长度：范数

向量的长度叫范数（norm），记作 ‖a‖。计算方式就是勾股定理的高维推广 —— 每个分量平方，加起来，再开根号。

为什么要长度？因为 AI 需要衡量"这个向量有多大"。比如梯度太长会导致训练不稳定，这时就把梯度归一化（除以其长度），让它只保留方向。

为什么 AI 离不开向量？

因为一切都能变成向量，而向量一旦有了统一形式，数学工具就能通用：

对象怎么变成向量维度示例
一张图片每个像素的灰度值依次排列28×28 → 784 维
一段文本每个词映射为词向量，再堆成矩阵512 词 × 768 维
一段语音切成小段，每段提取频谱特征每秒约 100 帧 × 80 维
一个用户年龄、消费额、点击历史统计几百到几千维
一个词Embedding 层查表得到300 ~ 4096 维
◆ 这是 AI 的第一次"数学翻译"

现实世界的任何东西 → 向量。这个动作叫 Embedding（嵌入）。它一旦完成，AI 就再也"看不见"原始世界了，它只看见向量。所以有个说法：一个好的 Embedding，抵得上半个模型。

02矩阵：不是表格，是"空间的变形术"

教科书把矩阵画成方方正正的数表，这不直观。矩阵真正的身份是：一个把向量搬来搬去的函数。

把矩阵看成"变形指令"

单位矩阵 I = [[1,0],[0,1]] 的效果是"什么都不改变"。一旦你改动里面的数，整个平面就开始变形：拉伸、压缩、旋转、剪切。

下面这个演示，你可以自由调整 2×2 矩阵的四个数，观察灰色网格（原始空间）如何被扭曲成蓝色网格（变换后的空间）。注意两个箭头 —— 它们是基向量 (1,0) 和 (0,1) 被搬运后的落点，矩阵的列，就是基向量的新位置。

矩阵 = 空间变形器
行列式 det = 1.00 —— 它表示面积被放大的倍数。det = 1，面积不变。当 det 变成 0，整个平面被压成一条线，信息不可逆地丢失了。

矩阵乘向量：一切 AI 计算的基本动作

矩阵 A 乘以向量 x，得到新向量 y。用"变形"解释：把 x 这个点，按 A 的规则搬到新位置。用"计算"解释：y 的每个分量，都是 x 的各分量加权求和。

这一行公式，就是神经网络里"全连接层"的全部内容。一次前向传播 = 几百次这样的矩阵乘法。GPU 之所以是 AI 的燃料，就是因为它能每秒做几万亿次这种"乘加"。

神经网络的每一层，都是矩阵

把前面的概念串起来，一个最简单的神经元层长这样：

一个全连接层：输入 → 加权 → 激活
左边 4 个输入节点，右边 3 个输出节点，中间每条连线都是一个权重（属于矩阵的一行）。连线上的数值会随着训练不断调整，这就是"学习"的字面含义。
◆ 为什么 AI 能有"智能"？

单个矩阵只能做线性变换（拉、压、转），很笨。但如果在线性变换之间插入非线性激活函数，再堆叠很多层，这个复合函数就能逼近任何连续函数 —— 这就是通用近似定理。所以 AI 的能力 = 矩阵的堆叠 × 非线性的注入。

⚠ 维度要能对上

(m×n) 的矩阵只能乘 (n×1) 的向量，结果 (m×1)。前一个矩阵的列数必须等于后一个的行数。你以后遇到 90% 的报错都是维度不匹配，看到 shape 不对就先算这个。

03点积：AI 判断"像不像"的唯一标准

你搜"苹果手机"，为什么不会返回"苹果园"？答案藏在点积里。

点积做了什么

两个向量逐项相乘再求和，得到一个数。这个数有一个极其重要的几何含义：衡量两者方向的一致性。

θ 是两向量的夹角。方向相同（θ=0°）→ 点积最大；垂直（θ=90°）→ 点积为 0，表示"毫无关系"；方向相反（θ=180°）→ 点积为负。

注意力机制 = 一堆点积

Transformer 之所以叫"注意力"，核心计算就是点积：

直觉版本：读句子"小明把书放在桌上，因为它太重了"——模型要判断"它"指什么，就计算"它"的 Q 和前面每个词的 K 的点积，看谁最相关。整句相关度排序，全靠点积。

04导数：AI 怎么知道自己"错在哪"

训练 AI 的过程，就是不断问一个问题："我把这个参数调大一点点，错误会变大还是变小？"这个问题的数学答案，就是导数。

导数的本质：一个放大镜

导数不是"斜率公式"，它的本质是当你把输入推进一丁点，输出会变化多少。它是变化率的度量。

下面这个演示里，橙色点可以在曲线上滑动。蓝色直线是切线——它紧紧贴着曲线，切线的斜率就是导数。你会看到：上坡时导数为正（蓝色），下坡时导数为负（红色），山谷处导数为 0。

两种求导方式

🧮解析求导：纸笔推导

用规则算出导函数。比如 f(x)=x² 的导数是 f′(x)=2x。精确、快，但对于几亿参数的神经网络，根本写不出来。

🔢数值求导：近似试探

取一个极小的 h，算 (f(x+h)−f(x))/h。概念简单但精度差、速度慢（每个参数都要算两遍前向）。

PyTorch 用的是第三条路 —— 自动微分（Autograd）：在计算过程中记录一张"计算图"，然后用链式法则从后往前一次性求出所有参数的导数。下一节详细说。

从导数到偏导数：参数太多了

神经网络不是 f(x) 这么简单，它是 f(w₁, w₂, ..., w₁₀₀₀₀₀₀) —— 一亿个参数。这时"导数"升级为偏导数：只关注某一个参数的变化，把其他参数都当作常数。

把所有偏导数收集起来，按顺序排成一个向量，就叫 梯度 ∇f。梯度指向"函数上升最快的方向"——记住这一点，这是下一节的钥匙。
◆ 一句话理解梯度

你在山坡上，梯度就是最陡上坡的方向和坡度。想让 f 变小（误差变小）？那就朝梯度的反方向走。这就是"梯度下降"这个名字的全部来历，没有任何神秘之处。

三个真实世界的坑

坑一：局部最优与鞍点

现实中的损失函数不是漂亮的碗，而是一片连绵山脉，到处是小坑（局部最优）和平缓的山脊（鞍点）。梯度在鞍点附近几乎为 0，你会误以为到终点了。

非凸地形：小球能到达真正的谷底吗
不同的起点会滑进不同的坑。这就是为什么初始化很重要 —— 但也要知道：在高维空间里，真正的"局部最优"其实很少，鞍点才是主要障碍。

坑二：遇到"峡谷"走不动

当损失曲面像一个又长又窄的峡谷（不同方向曲率差异极大），普通梯度下降会在峡谷两侧来回撞墙，前进极慢。

峡谷问题：为什么需要动量
灰 = 普通 SGD　蓝 = 带动量
普通 SGD（灰）在窄方向反复震荡，横向进展缓慢；加了动量（蓝）后，震荡方向被平均掉，横向速度累积起来，明显更快到达。这就是 Momentum 的几何解释。

坑三：梯度消失 / 爆炸

层数很深时，链式法则连乘会导致梯度指数级衰减（趋近 0，前面的层学不动）或指数级放大（变成 NaN）。ResNet 的残差连接（y = f(x) + x）就是为了让梯度有一条"高速公路"能直接传回去。

n 个小于 1 的数连乘 → 趋近 0（梯度消失）；n 个大于 1 的数连乘 → 爆炸。这就是深层网络难训练的数学根源。

06链式法则：反向传播的全部秘密

反向传播被说得神乎其神，但它的数学内容只有一个：链式法则。没有别的。

复合函数的求导

如果 y = f(u) 而 u = g(x)，那么 y 对 x 的导数等于"y 对 u 的导数"乘"u 对 x 的导数"。这叫链式法则，像链条一样一环扣一环。

生活化理解：速度 = 距离/时间。若距离取决于油耗，油耗取决于油门开度，那么"距离对油门的敏感度" = （距离对油耗的敏感度）×（油耗对油门的敏感度）。敏感度沿链条逐级传递相乘。

神经网络就是一条超长链条

一个 3 层网络的前向过程：x → z₁ → a₁ → z₂ → a₂ → z₃ → 损失 L。每个箭头都是一次函数变换，整条就是复合函数。反向传播就是从 L 出发，沿着链条往回，一级一级把梯度乘回去。

前向传播 vs 反向传播（点一下看动画）
橙色光点 = 前向传播（数据从输入流向损失）。蓝色光点 = 反向传播（梯度从损失流回各层）。注意反向传播并不需要重新算前向 —— 它在正向时就缓存了所有中间值。

为什么反向传播这么重要

关键在效率。假设有 100 万个参数：

方法计算量可行性
数值微分（逐个参数试探）100 万次前向传播❌ 慢到没法用
反向传播（一次反向）约等于 2 次前向传播✅ 这就是它伟大的地方

反向传播把求梯度的成本，从"正比于参数个数"降到"正比于计算层数"。正是这个数学技巧，让训练深网络在计算上成为可能。它是 1986 年被系统化的，但直到 2012 年算力跟上才真正引爆深度学习。

手动走一遍链式法则

前向：算出预测值

输入 x，经过各层得到预测 ŷ，与真实值 y 比较得损失 L。

求损失对输出的导数

∂L/∂ŷ。比如用 MSE 损失时，这一项就是 2(ŷ−y)。

逐层往回乘

∂L/∂W₃ = ∂L/∂ŷ · ∂ŷ/∂z₃ · ∂z₃/∂W₃，每一层把上一层的梯度接过来再乘上本层的局部导数。

用梯度更新参数

W ← W − η·∂L/∂W。全部参数一次性更新完，一轮结束。

◆ PyTorch 帮你做了什么

你写 loss.backward() 那一行，PyTorch 就在执行上面整个反向过程。它在正向计算时偷偷记录了计算图（谁依赖谁），调用 backward 时自动按链式法则倒着走一遍。你写的 forward 代码有多自然，反向传播就有多自动。

# 反向传播的极简演示（PyTorch 风格伪代码）
w = tensor([0.5], requires_grad=True)
x = tensor([2.0])
y_true = tensor([5.0])

for step in range(100):
    y_pred = w * x            # 前向：2 * 0.5 = 1.0
    loss = (y_pred - y_true)**2  # 损失：(1.0-5.0)^2 = 16
    loss.backward()           # ★ 反向传播：自动求出 dLoss/dw = 2*(y_pred-y)*x = -16
    with torch.no_grad():
        w -= 0.01 * w.grad  # 梯度下降：w = 0.5 - 0.01*(-16) = 0.66
        w.grad.zero_()          # 清空梯度，否则会累加

# 100 步后 w ≈ 2.5，因为 y = w * 2.0 = 5.0 → w = 2.5
# 你没有写任何求导公式，它自己学会了。

07概率：AI 从不说"是"，只说"多可能"

你问 AI 明天会不会下雨，它不该回答"会"，而该回答"70% 的概率会"。概率是 AI 处理不确定性的语言。

为什么必须用概率

因为有三种不确定性无法消除：

🎲世界本身随机

掷骰子、量子测量，本质不可预测。

🔍信息不完整

只看到部分特征，无法确定全貌。

🧠模型不够好

参数有限、训练数据有限，必然有误差。

面对这三种不确定性，硬给一个确定答案是不诚实的。给出一个概率分布，才是负责任的做法。

Softmax：把任意数变成概率

神经网络的最后一层输出的是一堆任意实数（叫 logits），比如 [3.2, 1.1, -0.5]。它们不能直接当概率 —— 有负数、不求和为 1。Softmax 负责把它们"压"成合法的概率分布：

做两件事：① 用指数函数保证所有输出为正；② 除以总和保证加起来等于 1。指数还有一个副作用 —— 放大差距：本来大 2 倍的数，经过指数后差距会大得多，让模型更"自信"。
Softmax 实时演示：拖动改变 logits
上排是原始 logits（可为负、无约束），下排是 softmax 后的概率（全部为正、和为 1）。
✦ 温度参数就是在这里动手脚

你用过 API 里的 temperature 吧？它的本质就是在 softmax 前把 logits 除以 T：softmax(z/T)。
· T < 1 → 差距被放大 → 输出更确定、更保守
· T > 1 → 差距被压缩 → 输出更随机、更有创意
· T → 0 → 退化成"永远选最大那个"

条件概率与独立性

P(A|B) 读作"在 B 发生的条件下，A 发生的概率"。语言模型做的全部事情就是算这个：P(下一个词 | 前面所有的词)。

GPT 每次只做一件事：给定前文，算出词表里每个词作为下一个词的概率，然后按概率采样。重复几千次，就生成了一整篇文章。大模型 = 一个超强的条件概率计算器。

08分布与贝叶斯：给不确定性画个形状

概率告诉我们"多大可能"，分布告诉我们"可能性是怎么铺开的"。

正态分布：为什么它无处不在

正态分布（高斯分布）由两个参数决定：均值 μ（中心在哪）和标准差 σ（多分散）。它钟形的曲线出现在身高、测量误差、神经网络权重初始化等无数场景。

理论上叫中心极限定理：大量独立随机因素叠加的结果，趋近正态分布。这正是它如此普遍的原因。

正态分布：拖动 μ 和 σ，看曲线怎么变
灰色阴影区域表示 μ±σ 区间，覆盖约 68% 的概率。μ±2σ 覆盖约 95%，μ±3σ 覆盖约 99.7% —— 这就是常说的"3σ 原则"。

三种常用分布，各有各的用场

分布描述什么AI 中的用途
伯努利 / 二项抛硬币式的二选一二分类任务、判断是否垃圾邮件
类别分布多选一（K 个类别）多分类、语言模型预测下一个词
正态分布连续值围绕中心波动权重初始化、VAE 的隐空间、扩散模型加噪声

贝叶斯定理：用新证据更新信念

贝叶斯定理可能是最有"哲学味"的数学公式。它回答：看到新证据后，我应该多大程度改变原来的判断？

P(H) 先验 —— 看到证据前的判断
P(E|H) 似然 —— 如果假设成立，看到这个证据的可能性
P(H|E) 后验 —— 看到证据后的更新判断

一句话：后验 ∝ 似然 × 先验。学习 = 不断用新数据更新信念。
贝叶斯更新：疾病检测的现实陷阱
一个"99% 准确"的检测，在患病率只有 1% 的人群里，阳性结果意味着真正患病的概率只有 —。这就是为什么医生要复查 —— 先验太低时，再准的检测也会被假阳性淹没。
✦ 这个反直觉的结论值得记住

罕见事件的检测，即便准确率很高，阳性结果也大概率是虚惊一场。这不是检测的问题，是数学的必然。任何涉及"筛查""风控""异常检测"的场景，都要先想清楚先验概率。

09信息熵与交叉熵：AI 的"成绩单"

AI 要学习，就必须先能量化"错得有多离谱"。这个度量就是损失函数，而分类任务最常用的那个，源自信息论。

信息熵：不确定性有多少

熵衡量一个概率分布的"混乱程度"。如果一件事必然发生，信息量为 0（毫无惊喜）；如果各种结果概率均等，信息量最大（最意外）。

单位是比特（用 log₂ 时）。抛一枚均匀硬币 H=1 bit（最大）；抛一枚两面相同的假硬币 H=0 bit。熵 = 平均"意外程度"。
熵：公平硬币 vs 作弊硬币
熵 = 1.000 bit　p=0.5 时熵最大，结果最难预测。

交叉熵：衡量"预测分布"和"真实分布"的差距

这就是分类任务的主力损失函数。真实标签是一个 one-hot 分布（答案只有一个是真的），预测是一个概率分布，交叉熵衡量两者有多远。

LOSS
由于 y 是 one-hot（只有一个位置是 1），这个求和实际只剩一项：L = −log(正确类别的预测概率)。

看结果有多直观：
· 预测正确答案的概率 = 0.9 → Loss = 0.105（小）
· 预测正确答案的概率 = 0.5 → Loss = 0.693（中）
· 预测正确答案的概率 = 0.01 → Loss = 4.605（大）

预测越自信且正确，loss 越小；越自信但错误，惩罚越狠。
交叉熵损失曲线：为什么"自信地错"会被狠狠惩罚
Loss = −ln(q) = 0.357　
⚠ 一个常见混淆

MSE（均方误差）用于回归任务（预测房价、温度这类连续值），loss = (ŷ−y)²。
交叉熵用于分类任务（判断类别）。
用错会怎样？分类任务用 MSE，梯度会变得很小，收敛极慢 —— 这是新手最常踩的坑之一。

◆ 大模型的训练目标就是这个

GPT 的训练目标本质上就是一个巨大的交叉熵：预测下一个词。给它"今天天气真"这五个字，正确答案是"好"，模型输出词表里每个词的概率，然后算交叉熵。

就这么简单的一件事，在几千亿参数的规模上重复几万亿次，就涌现出了推理、编程、翻译能力。复杂度来自规模，不来自目标的复杂。

10从 SGD 到 Adam：优化器的进化史

有了梯度，还得决定"怎么用它"。优化器的任务就是：让每一步都走得又快又稳。

三代优化器

第一代：SGD 随机梯度下降

不用全部数据算梯度（太慢），每次只用一小批（batch）。梯度有噪声，但训练速度快得多，而且噪声有时还能帮助跳出小坑。

第二代：Momentum 动量

给梯度加上"惯性"。想象一个球从山上滚下，即使撞到小坑也能凭借速度冲过去。数学上就是对历史梯度做指数加权平均。

β 通常取 0.9，意味着当前速度大约由最近 10 步的梯度共同决定。这是解决"峡谷震荡"的关键。

第三代：Adam 自适应学习率

Adam = Momentum + RMSProp。它对每个参数单独调整学习率：梯度一直很大的参数，步子调小；梯度一直很小的参数，步子放大。这样即使不同参数的尺度差异极大，也能协调前进。

m̂ 是梯度的一阶矩估计（动量的思想），v̂ 是二阶矩估计（梯度的平方的均值）。除以 √v̂ 就是"按梯度大小归一化"。ε 是防止除零的小常数（通常 1e-8）。
三种优化器赛跑：看谁先到终点
■ 灰 = SGD　 ■ 蓝 = Momentum　 ■ 绿 = Adam　 在等高线地形上，Adam 通常最快到达最优点并稳定住。

怎么选？一张实用对照表

优化器优点缺点什么时候用
SGD + Momentum泛化性能好，最终精度常更好需要精调学习率，收敛慢CV 任务、追求极致精度
Adam / AdamW对学习率不敏感，收敛快泛化有时略差Transformer、NLP、快速实验
RMSProp适合非平稳目标、RNNα 需调序列模型、强化学习
Lion / 新变体显存占用更低相对新，调参经验少大模型训练省显存
✓ 默认选择

拿不定主意就用 AdamW，学习率 1e-3 或 3e-4，权重衰减 0.01。这个组合能应付 80% 的场景。想榨干最后一点精度，再换 SGD+Momentum 慢慢调。

还没完：学习率调度

固定学习率不是最优解。训练初期需要大一点快速下降，后期需要小一点精细收敛。常见策略：

预热 Warmup

前几百步从极小逐渐升到目标值，避免初期梯度不稳导致发散。

余弦退火

学习率按余弦曲线平滑衰减到接近 0，是大模型最常用的方案。

阶梯衰减

每过若干个 epoch 就砍一半，简单粗暴但有效。

11实战：用刚学的数学，手搓一个神经网络

现在把四门数学全部串起来，做一个能真正学会"异或（XOR）"的最小神经网络。这个任务单层感知机做不了，必须至少一层隐藏层 —— 正好用来验证前面所有概念。

为什么选 XOR

XOR 规则：两个输入相同输出 0，不同输出 1。这四个点在平面上无法被一条直线分开，所以单层网络永远学不会。这个历史性难题曾让神经网络研究停滞十多年，解决它的钥匙就是"加一层隐藏层 + 非线性激活"。

完整实现（可直接运行）

不用任何深度学习框架，纯 NumPy 手写前向 + 反向传播。每一行都对应前面章节的数学。

import numpy as np

# ---------- 1. 数据：XOR 的四个点 ----------
X = np.array([[0,0], [0,1], [1,0], [1,1]])
y = np.array([[0], [1], [1], [0]])

# ---------- 2. 激活函数：引入非线性 ----------
# 没有它，再多层也只是线性变换的叠加，依然分不开 XOR
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_deriv(a):        # 注意：输入是激活后的值 a
    return a * (1 - a)            # σ'(z) = σ(z)(1-σ(z))

# ---------- 3. 初始化参数（矩阵！第 02 章） ----------
np.random.seed(42)
W1 = np.random.randn(2, 4) * 0.5   # 输入层 2 → 隐藏层 4
b1 = np.zeros((1, 4))
W2 = np.random.randn(4, 1) * 0.5   # 隐藏层 4 → 输出层 1
b2 = np.zeros((1, 1))

lr = 0.5                        # 学习率（第 05 章）

for epoch in range(10000):
    # ===== 前向传播：一串矩阵乘法 + 激活 =====
    z1 = X @ W1 + b1              # 线性变换
    a1 = sigmoid(z1)              # 非线性激活
    z2 = a1 @ W2 + b2
    y_hat = sigmoid(z2)           # 输出 0~1 的概率

    # ===== 计算损失：二元交叉熵（第 09 章） =====
    loss = -np.mean(y*np.log(y_hat+1e-8) + (1-y)*np.log(1-y_hat+1e-8))

    # ===== 反向传播：链式法则一路往回乘（第 06 章） =====
    dz2 = (y_hat - y)                      # dL/dz2：交叉熵配 sigmoid 化简后就是这么干净
    dW2 = a1.T @ dz2                       # 梯度：链式法则中的“上一层输出 × 本层误差”
    db2 = np.sum(dz2, axis=0, keepdims=True)

    da1 = dz2 @ W2.T                       # 误差回传到隐藏层
    dz1 = da1 * sigmoid_deriv(a1)
    dW1 = X.T @ dz1
    db1 = np.sum(dz1, axis=0, keepdims=True)

    # ===== 梯度下降更新参数（第 05 章） =====
    W2 -= lr * dW2;  b2 -= lr * db2
    W1 -= lr * dW1;  b1 -= lr * db1

    if epoch % 2000 == 0:
        print(f"epoch {epoch:5d}  loss = {loss:.4f}")

# ---------- 4. 验证：应该输出 0, 1, 1, 0 ----------
print("预测结果：", y_hat.round(3).ravel())
# 大约输出 [0.02, 0.98, 0.98, 0.02] —— 它学会了。
◆ 对照检查：每一行代码对应的数学

X @ W1 → 第 02 章矩阵乘法
sigmoid(z1) → 第 07 章把数值压成概率
loss → 第 09 章交叉熵
dz2 = y_hat - y → 第 04 章导数（一个漂亮到不真实的化简结果）
a1.T @ dz2 → 第 06 章链式法则
W2 -= lr * dW2 → 第 05 章梯度下降

整份代码里没有一行是"魔法"，全是前面讲过的内容。你已经在用它们了。
