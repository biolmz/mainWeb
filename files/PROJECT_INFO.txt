云端笔记系统 - 项目文件清单
================================

核心文件（3个）：
  index.html   - 主页面，包含所有UI结构
  styles.css   - 完整样式，响应式设计
  app.js       - 核心逻辑（COS交互、笔记CRUD、自动保存）

部署文件（2个）：
  404.html     - GitHub Pages SPA重定向
  .github/workflows/deploy.yml  - 自动部署工作流

文档（1个）：
  README.md    - 完整使用说明和部署指南

依赖（CDN加载，无需安装）：
  cos-js-sdk-v5  - 腾讯云COS JavaScript SDK
  marked         - Markdown解析器
  highlight.js   - 代码语法高亮

技术栈：
  纯前端（无后端服务器）
  Vanilla JS（无框架依赖）
  localStorage（本地配置存储）
  腾讯云COS（笔记数据存储）

架构：
  浏览器 ←HTTPS→ 腾讯云COS
  GitHub Pages → 托管静态文件
