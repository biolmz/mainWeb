# 📝 云端笔记系统

一个基于 **腾讯云 COS** 存储的纯前端笔记应用，支持 Markdown 编辑、实时预览、自动保存、多设备同步。

> 🌐 **Live Demo**: `https://你的用户名.github.io/note-system/`

---

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 📝 Markdown 编辑 | 支持完整 Markdown 语法 + 代码高亮 |
| ☁️ 云端存储 | 笔记自动保存到腾讯云 COS 对象存储 |

## 🚀 快速部署

### 第一步：创建腾讯云 COS 存储桶

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/cos)
2. 点击 **创建存储桶**
3. 配置参数：
   - **名称**：自定义（如 `my-notes-1250000000`）
   - **地域**：选择离你最近的（如广州、上海、北京）
   - **访问权限**：**私有读写**（推荐）
4. 记录 **存储桶名称** 和 **地域代号**（如 `ap-guangzhou`）

### 第二步：获取 API 密钥

1. 进入 [API 密钥管理](https://console.cloud.tencent.com/cam/capi)
2. 创建或获取已有的 **SecretId** 和 **SecretKey**
3. ⚠️ **安全提示**：
   - 建议创建子账号，仅授予 COS 相关权限
   - 密钥仅存储在浏览器 localStorage，不会发送到第三方

### 第三步：部署到 GitHub Pages

1. **Fork 或 Clone 本仓库**
   ```bash
   git clone https://github.com/你的用户名/note-system.git
   cd note-system
   ```

2. **推送到 GitHub 仓库**

3. **开启 GitHub Pages**
   - 进入仓库 → **Settings** → **Pages**
   - Source 选择 `main` 分支（或 `gh-pages`）
   - 点击 Save

4. **访问你的笔记系统**
   ```
   https://你的用户名.github.io/note-system/
   ```

### 第四步：首次配置

1. 打开网页，设置访问密码（至少4位）
2. 点击左下角 ⚙️ **设置**
3. 填入腾讯云 COS 信息：
   - **SecretId** / **SecretKey**
   - **存储桶名称**（如 `my-notes-1250000000`）
   - **存储桶区域**（如 `ap-guangzhou`）
4. 点击 **测试连接** 验证配置
5. 点击 **保存配置**

## 🔐 安全说明

| 安全措施 | 说明 |
|---------|------|
| 私有存储桶 | COS 存储桶设为私有，仅密钥持有者可访问 |
| 前端加密 | 密码验证在浏览器本地完成 |
| 密钥存储 | SecretKey 仅存 localStorage，不上传任何服务器 |
| HTTPS | GitHub Pages 全站 HTTPS 加密传输 |
| 子账号建议 | 建议使用仅含 COS 权限的腾讯云子账号密钥 |

## 🙋 FAQ

**Q: 密码忘记了怎么办？**
A: 打开浏览器控制台，执行 `localStorage.removeItem('noteSystem_password')` 清除密码，然后刷新页面重新设置。

**Q: 笔记数据存在哪里？**
A: 所有笔记以 JSON 文件形式存储在你的腾讯云 COS 存储桶中，路径为 `notes/{noteId}.json`。

**Q: 可以在多台设备上使用吗？**
A: 可以！在任何设备上打开网页，输入相同的 COS 配置和密码，即可同步所有笔记。

**Q: 支持图片上传吗？**
A: 当前版本通过 Markdown 图片链接引用外部图片。后续版本可扩展直传 COS 功能。

**Q: 如何备份所有笔记？**
A: 在腾讯云 COS 控制台，选择存储桶 → 文件列表 → 全选 → 下载，即可一键备份所有笔记。
