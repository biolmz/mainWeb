关于本项目

一个纯前端实现的 PDF 处理工具箱，覆盖日常最常见的五种 PDF 操作。

💡 项目介绍

本项目提供 PDF 合并、PDF 拆分、提取页面、提取文字、提取图片、 OCR 扫描件识别、PDF 压缩、转 Word / Excel 八项核心能力。所有处理都在浏览器本地完成： 打开页面 → 选择文件 → 处理 → 下载，全程无需联网上传，也没有文件大小、数量上的服务器限制。

⚙️ 技术实现

  • 📚 pdf-lib合并、拆分、提取页面、压缩重建（创建/拷贝页面与保存 PDF）
  • 🖨️ pdf.js（Mozilla）解析 PDF 结构、渲染页面、提取文本、内嵌图片与页面坐标
  • 🔍 Tesseract.jsOCR 扫描件识别（chi_sim / eng 语言包本地化，含 SIMD 加速）
  • 📦 JSZip多文件打包 ZIP；并用于生成 docx / xlsx（Office Open XML）文件
  • 🧱 原生 HTML / CSS / JavaScript无构建工具、无后端依赖，静态托管即可运行

🛡️ 隐私与安全

您的文件始终停留在本地设备中，浏览器负责全部计算，不会发生任何上传行为。 关闭页面后，文件数据即从内存中释放，适合处理合同、证件等敏感材料。

⚠️ 使用限制与提示

  • ✔ 受密码保护（加密）的 PDF 无法处理，请先解除密码。
  • ✔ 扫描版 / 图片型 PDF 没有文字层，提取文字为空属正常；请使用「OCR 识别」功能。
  • ✔ OCR 首次使用需下载语言包（约 2-5 MB），识别速度取决于页数与精度设置。
  • ✔ PDF 压缩会将页面栅格化为图片：文字型 PDF 压缩后将不可复制、不可搜索。
  • ✔ 转 Word / Excel 基于文本提取：不含原排版样式，Excel 表格为坐标近似识别。
  • ✔ 超大文件（数百 MB）建议使用现代浏览器（Chrome / Edge / Firefox 最新版）。
  • ✔ 提取图片仅针对 PDF 内嵌的图像对象；背景图、矢量图形不会被提取。
  • ✔ 为避免重复工作，页面刷新后已选择文件会清空，属预期行为。
