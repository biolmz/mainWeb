⚙️ COS 存储配置

🔑 腾讯云 COS 配置

建议使用仅含 COS 权限的子账号密钥，数据存储在你的私有存储桶中

📖 使用说明

  1. 在腾讯云控制台创建 COS 存储桶（建议私有读写）
  2. 创建子账号并仅授予该存储桶的读写权限
  3. 获取子账号的 API 密钥（SecretId / SecretKey）
  4. 填写上方配置信息并保存
  5. 开始写笔记，数据自动加密上传到你的存储桶
⚠️ 密钥仅存储在浏览器 localStorage 中，不会发送到任何第三方服务器。
⚠️ 由于是纯前端应用，建议使用权限受限的子账号密钥而非主账号密钥。
