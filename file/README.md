## 🚀 快速部署

### 第一步：创建腾讯云 COS 存储桶

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/cos)
2. **创建存储桶**：名称自定义（如 `my-notes-1250000000`），地域选最近，权限选**私有读写**
3. 记录 **Bucket 全名**（含 APPID 后缀）和 **地域代号**

### 第二步：创建子账号密钥（安全推荐）

1. 进入 [CAM 访问管理](https://console.cloud.tencent.com/cam)
2. 创建子用户 → 仅勾选 `QcloudCOSDataFullControl` 策略
3. 创建 API 密钥 → 记下 **SecretId** 和 **SecretKey**

### 第三步：部署到 GitHub Pages

```bash
git clone https://github.com/你的用户名/note-system.git
cd note-system
# 把修改后的文件推上去
git add . && git commit -m "deploy v2.0" && git push
```

仓库 → **Settings → Pages** → Source 选 `main` → Save

### 第四步：首次配置

1. 打开网页 → 设置访问密码（≥4 位）
2. 点 ⚙️ → 填入 SecretId / SecretKey / Bucket / Region
3. 点 **测试连接** → 确认 ✅ 后点 **保存配置**

## 🔐 安全说明

| 安全措施 | 实现方式 |
|---------|---------|
| **XSS 防护** | 预览渲染用 DOMPurify 消毒 HTML |
| **密钥遮蔽** | 设置页密码字段可切换显示/隐藏 |
| **子账号隔离** | 建议仅授予 COS 权限的密钥 |
| **私有存储桶** | 数据非公开，仅签名请求可访问 |
| **HTTPS 全链路** | GitHub Pages + COS 均强制 HTTPS |
| **本地密码** | 访问密码仅存 localStorage，不上传 |

## 🔄 多端同步原理

```
设备A 编辑 → 保存时写入 updatedAt 时间戳 + deviceId
                    ↓
          COS 存储桶更新
                    ↓
设备B 获得焦点/可见 → 检测 updatedAt > 本地缓存
                    ↓
         拉取云端版本 → 与本地比较
                    ↓
       有差异 → 弹出冲突对话框
       无差异 → 静默更新
```

**冲突解决**：当同一篇笔记在多设备同时编辑时，打开笔记会检测云端版本是否更新，如有冲突弹出对话框让你选择保留哪个版本。

## 🙋 FAQ

**Q: 保存按钮点了没反应？**
A: 检查 Console 有没有红色报错。最常见是 CORS 没配或 Bucket 名没带 APPID。

**Q: 多设备打开笔记冲突了怎么办？**
A: 系统会自动检测并弹出对话框，让你选择保留云端版本还是本地版本。

**Q: 导入的文件格式怎么判断？**
A: 优先按扩展名判断（.md→MD, .html→HTML, .json→JSON），无扩展名时自动检测内容。

**Q: 离线时能写笔记吗？**
A: 可以写，但保存会失败。恢复网络后系统会自动同步。

**Q: 如何备份所有笔记？**
A: 点侧边栏 📤 按钮一键导出全部，或到 COS 控制台批量下载。
